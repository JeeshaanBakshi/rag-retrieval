About

Keywords miss meaning.

Problem

Same idea, different words

Keyword search can't match "how is the scene stored?" to "implicit volumetric representation".

Built

A 5-step retrieval pipeline

Chunk the text, turn every chunk into a 384-number vector, rank them against the question.

Insight

Retrieval is linear algebra

Similar meanings point in similar directions, so cosine similarity finds them.

How it works

Five steps, straight from app.py.

  1. 01

    Read the document

    One text file: an article on NeRF.

    with open("text.txt") as file:
    content = file.read()
  2. 02

    Split into overlapping chunks

    Overlap keeps an idea whole when a chunk edge cuts it.

    cs = [content[0:size]]
for i in range(size, len(content), size - overlap):
    cs.append(content[i - overlap : i + size - overlap])
  3. 03

    Load the embedding model

    Similar meanings → similar vectors.

    model = SentenceTransformer("all-MiniLM-L6-v2")
  4. 04

    Embed every chunk

    Each chunk becomes 384 numbers.

    chunk_emb = [model.encode(chunk) for chunk in cs]
  5. 05

    Score and keep the top 3

    Cosine similarity between the question and every chunk.

    qem = model.encode(question).reshape(1, -1)
scores = [cosine_similarity(qem, e.reshape(1, -1))[0][0]
          for e in chunk_emb]
topscindex = topscindex[:3]   # after sorting, highest first
